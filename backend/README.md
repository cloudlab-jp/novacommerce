# NovaCommerce Backend

Backend API para la plataforma NovaCommerce, desarrollado con Spring Boot siguiendo una arquitectura modular orientada a servicios.

## Stack tecnológico

- Java 21
- Spring Boot 4
- Spring Data JPA
- Hibernate
- PostgreSQL 17
- Docker
- Maven

## Requisitos

Antes de ejecutar el proyecto debes tener instalado:

- Java 21+
- Maven 3.9+
- Docker Desktop

Verificar versiones:

```bash
java -version
mvn -version
docker --version
```
